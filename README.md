# Expensify

An AI-powered expense tracker with a conversational chatbot. Log expenses and ask natural language questions like "how much did I spend on Uber last month?"

## What it does

- Log and categorize daily expenses
- AI chatbot for querying spending history in plain English
- Analytics dashboard with spending insights
- Real-time data sync via Supabase

## Tech stack

- **Frontend:** React + TypeScript + Vite
- **UI:** shadcn/ui + Radix UI + Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **State:** TanStack React Query
